# Face Keys（Blender 5.1 対応）

3D ビューのサイドバーから、顔のシェイプキーを直接操作するためのアドオンです。
選択しているオブジェクトに関係なく（アーマチュアでポーズを付けている最中でも）、指定したメッシュのシェイプキーを動かせます。

## インストール
「編集 → プリファレンス → アドオン → ▼ → ディスクからインストール」で `face_keys-0.1.0.zip` を選びます。
3D ビューのサイドバー（N キー）に **Face Keys** タブが追加されます。

## 使い方
1. **Mesh** に顔のメッシュ（シェイプキーを持つもの）を指定します。
2. **Auto Detect** を押すと、名前から次のシェイプキーを見つけて設定します。
   - 目を閉じる（両目・左・右）→ 一覧に追加
   - 口の開閉 → 一覧に追加
   - 視線（上・下・左・右）→ Eye Look に割り当て
   - ARKit（`eyeBlinkLeft`・`eyeLookUpLeft`・`jawOpen` など）、VRChat（`vrc.blink`・`vrc.v_aa`）、MMD（`まばたき`・`あ`）、よくある独自名（`eye_close_L`・`eyelook_up`・`mouth_a`）に対応しています。
3. **Shape Keys** の一覧
   - 各行のスライダーで値を変更します。右のアイコンは、◇ ならこのフレームにキーなし、◆ ならキーありです。クリックすると、いつでも**今の値でキーを入れます**（キーがあれば上書き）。**Ctrl+クリック**でこのフレームのキーを削除します。キーのあるフレームで値を変えてまだキーに反映していないときは、アイコンが赤くなります。
   - Auto Keying がオンなら、スライダーを動かした時点でキーが入ります（Blender の標準動作）。
   - 下の欄で任意のシェイプキーを選んで **Add** で追加。− で一覧から外す（シェイプキー自体は消えません）。▲▼ で並べ替え。
   - 選択中の行は **Label** で表示名を変えられます。一覧の下の虫眼鏡で名前の絞り込みができます。
   - **Key All**（一覧と視線をまとめてキー挿入）、**Delete Keys**（現在フレームのキーを削除）、**Reset**（すべて 0 に）。
4. **Eye Look**（視線）
   - **2D Look Pad**：押してからマウスを動かすと四角いパッドが表示され、視線を上下左右に二次元で動かせます。クリック（または Enter）で確定、右クリック（または Esc）で取り消し。Shift で微調整、C で中央に戻します。パッドの左右は画面の左右に合わせてあり、キャラクターを前から見ても後ろから見ても、マウスを動かした方向に視線が動きます。
   - **X / Y のスライダー**：左（−1）〜右（+1）、下（−1）〜上（+1）。
   - **Key Look**：視線のシェイプキーにキーを挿入（右のボタンで削除）。視線をキーなしで変えた状態だと赤く「Key Look (not keyed!)」と表示されます（そのままフレームを移動したり、Auto Keying 中に他のスライダーを動かしたりすると、変更は消えます）。
   - Auto Keying がオンなら、X / Y スライダーやパッドで視線を変えたときに自動でキーが入ります。
   - **Look Keys**：上下左右それぞれに 2 つまでシェイプキーを割り当てられます（片目ずつのキーを両目分入れる場合など）。
     - **4 Keys / 2 Keys** で方式を切り替えます。**2 Keys** は「上下」「左右」を 1 つずつのシェイプキーで動かすモデル向けで、値が＋なら上・キャラクターの右、−なら下・キャラクターの左として扱います。逆に動く場合は、行の右の ⇄ ボタンで反転します。マイナスの値を使うため、必要に応じてシェイプキーの Range Min を −1 に広げます。
     - Auto Detect は `EyeUpDown`・`目_左右` のような名前を見つけると、自動で 2 Keys に切り替えます。**Pad Size** はパッドの大きさ（マウスの移動量）です。

## 注意
- ドライバーで動いているシェイプキー（FaceIt のコントローラーとつながったものなど）は、パネルから値を変えられません。一覧ではドライバーのアイコンが付き、Eye Look には警告が出ます。そのシェイプキーは、ドライバー元（FaceIt のコントロールリグなど）で動かしてください。
- 「左・右」はキャラクターから見た左右です。逆に動く場合は Look Keys の左右を入れ替えてください。
